**Libraries to verify (per CONTEXT.md):**

2. **SvelteKit 2 patterns** - Check all routes use:
   - Proper load function typing: `PageServerLoad`, `PageLoad`, `Actions`
   - `fail()` for validation errors in actions
   - Proper `+page.ts` vs `+page.server.ts` distinction

3. **Drizzle ORM patterns** - Check packages/db uses:
   - Type-safe queries with `db.query` or proper select
   - `eq()`, `and()`, `or()` from drizzle-orm for conditions
   - Proper null handling with strict TypeScript

4. **shadcn-svelte patterns** - Check UI components use:
   - `cn()` for class merging
   - Proper props patterns for bits-ui v1.0
