Build the gallery page with filtering:

1. Create GalleryFilter.svelte (based on research pattern):
   - Props with $bindable: selectedCategory, selectedStylist
   - Props: categories (array of {id, name}), stylists (array of {id, displayName})
   - Two filter sections: "Service Type" and "Stylist"
   - Each section has "All" button + buttons for each option
   - Use Button component with variant toggling (default when selected, outline when not)
   - Wrap in flex container with gap-4, mobile-friendly wrapping
   - Update bound values on click

2. Create /gallery/+page.ts:
   - Import type PageLoad
   - Get storyblokApi from parent()
   - Fetch gallery story: storyblokApi.get('cdn/stories/gallery', { version: ... })
   - If story exists, extract gallery_images from story.content
   - Parse each image to extract metadata (stylistId, categoryId from Storyblok fields)
   - Also fetch filter options:
     - Get serviceCategories from a server endpoint or inline data
     - Get active staff from /api/staff endpoint
   - Return { galleryItems, categories, stylists }
   - Handle gracefully if no gallery story exists (return empty array)

3. Create /gallery/+page.svelte:
   - Accept data via $props()
   - Create filter state: selectedCategory = $state('all'), selectedStylist = $state('all')
   - Compute filtered items using $derived:
     ```
     let filteredItems = $derived(
       data.galleryItems.filter(item => {
         const matchesCategory = selectedCategory === 'all' || item.categoryId === selectedCategory;
         const matchesStylist = selectedStylist === 'all' || item.stylistId === selectedStylist;
         return matchesCategory && matchesStylist;
       })
     );
     ```
   - Page structure:
     - svelte:head with title "Gallery | Expressions Hair Designs"
     - Heading "Our Work" (Cormorant Garamond)
     - Subheading explaining before/after transformations
     - GalleryFilter component with bound values
     - GalleryGrid with filtered items
     - Empty state if no items match filters

4. Fallback content when CMS not configured:
   - Show message "Gallery coming soon" with placeholder
   - Still show filter UI (disabled or empty)
  </action>
