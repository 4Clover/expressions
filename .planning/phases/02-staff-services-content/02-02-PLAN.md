Install and configure Storyblok SDK:

1. Install packages:
   ```bash
   pnpm --filter apps/web add @storyblok/svelte
   pnpm --filter apps/web add -D @vitejs/plugin-basic-ssl
   ```

2. Update vite.config.ts:
   - Import basicSsl from '@vitejs/plugin-basic-ssl'
   - Add basicSsl() to plugins array (order: tailwindcss, sveltekit, basicSsl)
   - This enables HTTPS in dev for Storyblok visual editor iframe

3. Update .env.example:
   - Add: VITE_STORYBLOK_ACCESS_TOKEN=your_preview_token_here
   - Note: VITE_ prefix exposes to client (needed for API calls)

Important: Storyblok Visual Editor requires HTTPS. The basicSsl plugin generates a self-signed cert for localhost.
  </action>

   - Register components object mapping Storyblok names to Svelte components:
     - 'page' -> Page
     - 'hero' -> Hero
     - 'services-overview' -> ServicesOverview
     - 'service-preview-card' -> ServicePreviewCard
     - 'staff-highlights' -> StaffHighlights
     - 'contact-info' -> ContactInfo
     - 'rich-text-block' -> RichTextBlock

2. Create src/routes/+layout.ts (NOT +layout.server.ts):
   - Import initStoryblok from '$lib/storyblok'
   - Import useStoryblokApi from '@storyblok/svelte'
   - Call initStoryblok() at module level
   - Export load function that returns { storyblokApi: useStoryblokApi() }

Note: Initialization happens at module level, not inside load(), per @storyblok/svelte pattern. The load function provides storyblokApi to child pages via parent().

Create Storyblok block components using research patterns:

All components must:
- Use `let { blok } = $props()` for Svelte 5
- Use `use:storyblokEditable={blok}` on root element
- Import storyblokEditable from '@storyblok/svelte'
- Access fields via blok.fieldName (not destructured)

1. Page.svelte:
   - Container component that renders nested blocks
   - Import StoryblokComponent from '@storyblok/svelte'
   - Loop over blok.body array, render each with StoryblokComponent

2. Hero.svelte:
   - Fields: headline, subheadline, background_image (asset), cta_text, cta_link
   - Full-width section with generous padding (py-24 md:py-32 lg:py-40)
   - Centered text, Cormorant Garamond heading (text-4xl md:text-5xl)
   - Optional CTA Button with rose gold styling
   - Use Storyblok Image Service for background_image optimization

3. ServicesOverview.svelte:
   - Fields: headline, services (array of nested ServicePreviewCard blocks)
   - Section with muted background
   - 3-column grid of service cards
   - Render nested blocks with StoryblokComponent

4. ServicePreviewCard.svelte:
   - Fields: name, description, icon (asset)
   - Card component with icon, title, description
   - Not a link (just preview; actual services page for details)

5. StaffHighlights.svelte:
   - Fields: headline, description, staff_ids (text array of DB staff IDs)
   - Note: Will fetch staff from DB using these IDs in Plan 02-03
   - For now, render placeholder cards showing staff_ids
   - Section with 3-column grid

6. ContactInfo.svelte:
   - Fields: address, phone, email, hours (richtext), google_maps_embed_url
   - Two-column layout: contact details + map iframe
   - Import renderRichText from '@storyblok/svelte' for hours
   - Phone as tel: link, email as mailto: link

7. RichTextBlock.svelte:
   - Fields: content (richtext)
   - Use renderRichText to convert to HTML
   - Apply prose classes for typography

Helper function for all components using images:
```typescript
function optimizeImage(url: string, width: number = 800, quality: number = 80) {
  if (!url) return '';
  return `${url}/m/${width}x0/filters:quality(${quality})`;
}
```
