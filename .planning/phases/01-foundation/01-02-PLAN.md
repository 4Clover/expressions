  <action>
Create schema files for Phase 1 foundation:

1. Create packages/db/src/schema/profiles.ts:
   - profiles table: id (uuid), userId (uuid), email (text), role (text, default 'customer'), createdAt, updatedAt
   - RLS policy: users can view/update own profile
   - Use pgPolicy from drizzle-orm/pg-core

2. Create packages/db/src/schema/staff.ts:
   - staff table: id (uuid), profileId (uuid FK), displayName (text), bio (text), photoUrl (text), specialties (text array), isActive (boolean), createdAt, updatedAt
   - No RLS yet (public read, admin write - handled in Phase 7)

3. Create packages/db/src/schema/services.ts:
   - serviceCategories table: id (uuid), name (text), displayOrder (integer), createdAt
   - services table: id (uuid), categoryId (uuid FK), name (text), description (text), durationMinutes (integer), priceType (enum: fixed/starting/range), priceMin (integer cents), priceMax (integer nullable cents), isActive (boolean), createdAt, updatedAt
   - staffServices table: id (uuid), staffId (uuid FK), serviceId (uuid FK), customPrice (integer nullable cents), isAvailable (boolean) - junction for per-stylist pricing

4. Create packages/db/src/schema/index.ts:
   - Export all tables from profiles, staff, services
   - Export relations if defined

5. Update apps/web/package.json:

6. Create apps/web/.env.example:
