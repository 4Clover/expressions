<task type="auto">
  <name>Task 1: Create payments schema with payment method and Square config tables</name>
  <files>packages/db/src/schema/payments.ts, packages/db/src/schema/index.ts</files>
  <action>
    Create `packages/db/src/schema/payments.ts` with:

    1. **paymentMethodTypeEnum** - pgEnum with values: 'venmo', 'cashapp', 'zelle', 'cash'

    2. **staffPaymentMethods** table:
       - id: uuid, primaryKey, defaultRandom
       - staffId: uuid, notNull, references staff.id
       - methodType: paymentMethodTypeEnum, notNull
       - handle: text (nullable - Zelle uses email, cash has no handle)
       - displayName: text (nullable - optional custom label like "Jane's Venmo")
       - isEnabled: boolean, notNull, default true
       - displayOrder: integer, notNull, default 0
       - createdAt: timestamp with timezone, notNull, defaultNow
       - RLS policy: "authenticated can manage own payment methods" for staff users
       - RLS policy: "public can view enabled payment methods" for select (to display in booking)

    3. **staffSquareConfig** table (for OAuth tokens):
       - id: uuid, primaryKey, defaultRandom
       - staffId: uuid, notNull, unique, references staff.id
       - merchantId: text, notNull
       - locationId: text, notNull
       - accessToken: text, notNull (NOTE: encrypt at rest in production via Supabase Vault)
       - refreshToken: text, notNull
       - tokenExpiresAt: timestamp with timezone, notNull
       - isEnabled: boolean, notNull, default true
       - createdAt: timestamp with timezone, notNull, defaultNow
       - updatedAt: timestamp with timezone, notNull, defaultNow
       - RLS policy: "staff can view own square config" for select

    4. **payments** table:
       - id: uuid, primaryKey, defaultRandom
       - appointmentId: uuid, notNull, references appointments.id
       - squarePaymentId: text, unique (nullable for pay-at-salon)
       - squareOrderId: text (nullable)
       - amountCents: integer, notNull
       - status: text, notNull ('pending', 'completed', 'failed', 'refunded')
       - paymentMethod: text, notNull ('square', 'pay_at_salon')
       - createdAt: timestamp with timezone, notNull, defaultNow
       - completedAt: timestamp with timezone (nullable)
       - RLS policy: "authenticated can manage payments" for all

    5. **processedWebhooks** table (idempotency):
       - eventId: text, primaryKey
       - eventType: text, notNull
       - processedAt: timestamp with timezone, notNull, defaultNow
       - RLS policy: "service role only" (no public/anon access)

    6. Add Drizzle relations:
       - staffPaymentMethodsRelations -> staff (one)
       - staffSquareConfigRelations -> staff (one)
       - paymentsRelations -> appointments (one)

    Export all tables, enums, and relations from index.ts.
  </action>
  <verify>pnpm --filter @repo/db check (TypeScript compiles)</verify>
  <done>payments.ts exports all 4 tables with proper types, relations, and RLS policies</done>
</task>
