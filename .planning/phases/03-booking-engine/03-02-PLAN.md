2. **generateAvailableSlots function** per RESEARCH algorithm:
```typescript
export function generateAvailableSlots(
  date: Date,
  schedule: { startTime: string; endTime: string }, // "09:00", "17:00"
  existingBookings: { startTime: Date; endTime: Date }[],
  serviceDuration: number, // minutes
  slotGranularity: number = 30
): TimeSlot[]
```

Algorithm:
- Parse schedule times, create slot boundaries for the target date
- Generate potential slots at 30-minute intervals
- Skip slots in the past (compare against now)
- Skip slots where service duration exceeds schedule end
- Skip slots that overlap with existing bookings
- Return remaining available slots with display string

Use date-fns for date arithmetic:
- `addMinutes`, `isBefore`, `isAfter`, `format` from 'date-fns'
- Do NOT use UTCDate for slot generation (salon times are local)

3. **getAvailableDatesForWeek function**:

export async function getAvailableDatesForWeek(

Returns dates within the week that have at least one available slot.

  <files>apps/web/src/routes/api/availability/+server.ts</files>
  <action>
Create GET endpoint at /api/availability:

**Query parameters:**
- staffId (required) - UUID of stylist
- serviceId (required) - UUID of service
- date (required) - YYYY-MM-DD format

**Logic:**
1. Validate required params (return 400 if missing)
2. Parse date string to Date object
3. Get weekday (0-6) from date
4. Query staffSchedule for this staffId + weekday + isActive=true
5. If no schedule, return `{ slots: [], message: "Stylist not available this day" }`
6. Query service for durationMinutes
7. Query appointments for this staffId on this date with status='confirmed'
8. Call generateAvailableSlots with schedule, bookings, duration
9. Return `{ slots: TimeSlot[] }`

**Error handling:**
- 400 for missing params
- 404 for service not found
- 200 with empty slots if no availability

Use dynamic import for db to handle missing DATABASE_URL gracefully (pattern from 02-01).
