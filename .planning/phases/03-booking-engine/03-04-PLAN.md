Create POST endpoint to execute cancellation:

**Logic:**
1. Get token from URL params
2. Find appointment by cancelToken
3. Validate appointment exists and is not already cancelled
4. Update appointment:
   - status = 'cancelled'
   - cancelledAt = now()
5. Return success

**Response:**
- 200: `{ success: true, message: 'Appointment cancelled' }`
- 404: `{ error: 'not_found', message: 'Appointment not found' }`
- 400: `{ error: 'already_cancelled', message: 'This appointment has already been cancelled' }`
- 500: `{ error: 'server', message: string }`

**Note:** Do NOT actually enforce 24-hour policy for demo. Just display the warning.
